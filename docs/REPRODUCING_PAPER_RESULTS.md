# Reproducing paper analyses

The analyses in the manuscript are organized into five components.

## 1. GEMF simulation recovery analyses

These simulations evaluate recovery of shared and modality-specific structure under known data-generating mechanisms.

Relevant scripts:

- `scripts/simulate_gemf_energy_data.py`
- `scripts/run_gemf_recovery_simulations.py`
- `scripts/summarize_gemf_recovery_simulations.py`

## 2. GEMF simulation rank-selection analyses

These simulations evaluate reconstruction-based shared-rank selection using the one-standard-error rule.

Relevant scripts:

- `scripts/run_gemf_rank_selection_simulations.py`
- `scripts/summarize_gemf_rank_selection_simulations.py`

## 3. MPI--LEMON fixed-dimension benchmark

This analysis compares representation families over fixed dimensions or shared ranks.

Relevant script:

- `scripts/outercv_fixed_budget_benchmark.py`

The main figure is generated by:

- `scripts/plot_partA_fixed_dimension_benchmark_clean.py`

## 4. MPI--LEMON reconstruction-based rank selection

This analysis selects representation dimension using inner cross-validation and the one-standard-error rule.

Relevant scripts:

- `scripts/outercv_pca_rankselect_1se.py`
- `scripts/outercv_gemf_rankselect_1se.py`
- `scripts/make_partB_rankselect_table.py`

## 5. GEMF visualization analyses

These scripts fit the final full-data GEMF model and export visualization objects.

Relevant scripts:

- `scripts/fit_and_export_gemf_panels.py`
- `scripts/plot_gemf_panels.py`
- `scripts/rank_gemf_factors_by_age.py`
- `scripts/make_gemf_main_montage.py`
